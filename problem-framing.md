## Solution Sketch
We introduce Tagging concept to help users make bio cards easily. Fandom Friends keeps a database of existing tags. User enters a set of tags of fandoms they're in, as well as desired activities like "drawing" or "going to cons", with autofill and auto detection of synonymous tags. Synonymous tags will be displayed as the text user entered, but will be recorded as the actual key in the database. Users can create a new tag, with exact key determined by the agent using search functions, or the user, when the tag is rare and can't be searched. User can star certain tags to be emphasized. Fandom Friends generates a bio card with the given tags, with live preview. User can customize the bio card's colors and font styles. User can add their social media links to their bio card.

User saves their bio card, can save a png, or click "Open to New Friends" and the bio card will display publicly.

Users meet each other by MutualMatching or Messaging. Users can find potential friends by searching for specific tags or browsing a “For You” page ranked by similarity in their interests and priorities. They can privately select “Interested” or “Pass” on another user. They can also direct message if they're brave. Two users receive a match notification when both select “Interested.”

Passing on someone removes that person from the user’s search results and “For You” page. Users can review their “Passed users” list and undo a pass at any time, making that person eligible to appear again.
